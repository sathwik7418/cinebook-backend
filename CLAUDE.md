Read docs/specification.md before implementing major features.

Follow the approved architecture.

Work incrementally by phase.

Do not implement multiple major phases at once.

After every phase:
- compile
- run tests
- fix errors
- update documentation
- update implementation-status.md

Never create fake implementations for core functionality.

Never put business logic in controllers.
